It was done with RPG Maker VX...But I was able to port it to the newest engine RPG Maker MV (higher resolution)...But the default characters for RPG Maker I really hate...The chibi style characters...So I generated my characters here:

http://www.geocities.jp/kurororo4/looseleaf/

The thing I really like about RPG maker is that you don't need to know any coding at all and it's easy to figure out...But they have a plugin engine...So you can code if you want to...

Some examples of this include the battle system or a script that allows you to swap parties with a whole other party (for characters in the game)..That's how I was able to pull of where you get into your spaceship and you fly as the ship..The ship is just "A character" that I swap with when I walk out the air-lock door...So ships have their own inventory and all that.

Without the party swap plugin...I would have had to program every instance of what might happen when you walk out the airlock door..But instead it's just one line now for "Swap Party"...Just some examples.

So I like that to get started you don't need to know shit, and then when you get more detailed you can plug it in...That's the way to develop in my view! Now they just need to do it for more 3d games as well.

I also prefer 2d because I can make the stuff myself in photoshop or any other graphics editing software.
